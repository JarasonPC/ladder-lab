# Security

## Reporting a problem

If you find a security problem in LadderLab, or a signed LadderLab file that did not come
from this project, report it privately: on the
[Security tab](https://github.com/JarasonPC/ladder-lab/security) of the repository, choose
**Report a vulnerability**. Please don't open a public issue for it.

Describe what you found and how to reproduce it; a `.ladder` file that shows the problem
helps. You will get an answer as soon as possible.

## Supported versions

Fixes go into the next release; only the latest version is supported. LadderLab tells you
when a new version is out (Help > Check for updates).

## Genuine downloads

Download LadderLab only from the
[Releases](https://github.com/JarasonPC/ladder-lab/releases) page. How the Windows builds
are made and signed is described in [CODE_SIGNING.md](CODE_SIGNING.md).
